## 📖 О проекте

**ПРОХОД‑1** — это автономный коротковолновый радиомаяк для индикации состояния распространения радиоволн на частоте **7 МГц**.  
Он помогает удалённым станциям (метео, научным, мониторинговым) принимать решение о начале сеанса передачи данных, **экономя до 88% энергии** аккумуляторов в условиях Арктики.

## 🧠 Принцип работы

Маяк непрерывно (или с заданным интервалом) излучает идентификационный сигнал на частоте **7 МГц**.  

Удалённая станция перед передачей данных прослушивает эфир на этой частоте:
- Если сигнал маяка уверенно принимается (превышает порог) — станция **включает свой передатчик**.
- Если сигнал слабый или отсутствует — станция **переходит в режим ожидания**, избегая лишних затрат энергии.
