О ПРОЕКТЕ
---------
ПРОХОД-1 – это автономный коротковолновый радиомаяк для индикации состояния распространения радиоволн на частоте 7 МГц. Он помогает удалённым станциям (метео, научным, мониторинговым) принимать решение о начале сеанса передачи данных, экономя до 88% энергии аккумуляторов в условиях Арктики.


ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ (V1.0)
---------------------------------
Параметр                           Значение
-----------------------------------------------------------------------
Рабочая частота                   7,000 МГц ± 1 кГц
Выходная мощность                 ~0,5 Вт (прототип)
Напряжение питания                12 В постоянного тока
Ток потребления                   ~0,2 А (в режиме передачи)
Микроконтроллер                   ESP32 (ШИМ-генератор)
Модуляция                         CW (азбука Морзе)
Передаваемые данные               Позывной, температура, давление, напряжение
Антенна                           Симметричный диполь (или с согласующим устройством)
Фильтрация                        ФНЧ 5-го порядка (Баттерворт) + П-контур
Диапазон температур               –40 … +50 °C (расчётно)


ПРИНЦИП РАБОТЫ
--------------
Маяк непрерывно (или с заданным интервалом) излучает идентификационный сигнал на частоте 7 МГц. Удалённая станция перед передачей данных прослушивает эфир на этой частоте. Если сигнал маяка уверенно принимается (превышает порог), станция включает свой передатчик. Если сигнал слабый или отсутствует – станция переходит в режим ожидания, избегая лишних затрат энергии.
